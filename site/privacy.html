Privacy

This site counts visits, and Clyde can count how it is used if you ask it to. Both are counts only: no cookies, no accounts, nothing that identifies you.

This website

What it counts
Which page was opened, which tab, screenshot tab, copy button or link to another site was clicked, and the site you came from, as a host name such as github.com (or a label like github-readme that a link carries in ?ref=).
What it does not
No cookie, no stored identifier, no fingerprint, no search or page text, and nothing from the address after the page name. The counter sees your IP address, as any web server does; GoatCounter uses it only to tell visitors apart, as a non-identifiable hash.
Do Not Track
If your browser sends Do Not Track or Global Privacy Control, nothing is sent. Automated browsers are flagged so they are not counted.
Switch it off
It sets one flag in this browser's local storage; nothing is sent about it.

The script is analytics.js, about a hundred lines, and it is the only script that reports. The counts go to the project's GoatCounter, an open-source counter that, in its own words, counts unique visits "without cookies using a non-identifiable hash". GoatCounter's privacy policy applies to what it receives.

Clyde and Bonnie

On for new installs
A new install has it on, and says so the first time Clyde runs in a terminal. If you already had Clyde, an update asks once and stays off unless you say yes. It is never switched on by itself in an editor, a script or CI. Stop it any time with clyde telemetry off, which also deletes what is queued. CLYDE_TELEMETRY=off and DO_NOT_TRACK=1 always win.
Counts only
How many tool calls failed, which size of model, which built-in provider was used (one you added yourself is just "custom"), which kind of provider error, how a tuning run ended, which Bonnie features get used (just the name, such as automations or themes). Never prompts, files, paths, model names or error text; every field is a number or a word from a fixed list.
See it first
clyde telemetry show prints exactly what is queued and everything that can be recorded. clyde telemetry off stops it and deletes the queue.
Everything else
Telemetry is only one of the ways Clyde uses the network. What leaves your machine lists all of them: what each sends, when, and how to turn it off.
Where it goes
Only while it is on, to a small Cloudflare Worker whose code is in the repository's worker folder. It re-checks every event, refuses anything off the list, and keeps only daily totals: no event, no install id and no address is stored. Cloudflare sees your IP address at its edge as with any web request; the Worker never reads it. You can send somewhere else, or nowhere, with clyde telemetry endpoint and clyde telemetry off.
