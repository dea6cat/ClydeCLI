What other harnesses don't do

The big vendor CLIs are built around one company's models. Clyde is built around all of them, and it checks which ones actually work.

cardShuffle routing

A virtual model that deals each turn to a real one, ranked by /eval. If a model errors, stalls or loops, the next card takes over. Tiers: high-roller, house, free, small.

Its own model eval

/eval tests every model you can reach on tool calls, then deals it a hand of 11 graded tasks. Broken models are hidden; results show latency and tokens per second.

Any provider, any key

13 built in, including Anthropic, OpenAI, Google, Mistral, NVIDIA, DeepSeek and OpenRouter, plus local Ollama and LM Studio. Any OpenAI-compatible endpoint joins with /login → custom.

Local models that fit

/models local searches ollama.com, Hugging Face GGUF and MLX, rates each one relax, balance or hard for your machine, and shows the cost before anything downloads.

Supply-chain scanning

Bundled SkillSpector scans skills, plugins, agents and MCP tool lists before the model sees them. Anything flagged do-not-install stays out until you allow it.

Bring your setup

Reads the memory files, skills, hooks, MCP servers and plugins you already made for Claude Code, Cursor, Gemini CLI, Codex and Copilot, and imports them only with a yes.

Everything a daily driver needs

The fundamentals are here too, covered by a suite of nearly 700 tests and a live shakedown against real providers.

Up and running in three steps

The installer sets up uv and Clyde, then clyde setup walks you through the rest.

01 · INSTALL 
curl -fsSL https://raw.githubusercontent.com/dea6cat/ClydeCLI/main/install.sh | sh
02 · CONNECT 
clyde login      # or export a provider key
03 · WORK 
cd your-project
clyde
Straight talk
  • The install is about 850 MB, mostly PyTorch for Laya, the bundled local model that spots stuck loops.
  • It's young: one maintainer, not yet hardened by a big user base. Issues and PRs are welcome.
  • No IDE integration yet. VS Code and JetBrains support is on the roadmap.
