ClydeCLI

A coding-agent harness for the terminal. Bring any LLM; Clyde gives it tools, permissions, a sandbox, undo and sessions.

curl -fsSL https://raw.githubusercontent.com/dea6cat/ClydeCLI/main/install.sh | sh

The model can be one of 13 providers, a local model through Ollama or LM Studio, or any OpenAI- or Anthropic-compatible endpoint. Written in Python, free for noncommercial use.

A real session

A three-file project with a leap-year bug, NVIDIA's muse-glimmer-30b in all-in mode, then /rewind to undo the fix. The dim italic lines are the model's own thinking.

When a model fails mid-turn

With cardShuffle:house as the model, Clyde picks a real model for each turn from the ones that passed /eval. Here Google answered HTTP 503 halfway through, so the turn moved to the next model and finished.

Checking which models work

/eval runs a tool call, a round trip and a hand of 11 graded tasks against every model your keys reach. Broken ones disappear from /models. The red line is a model that scored lower than at its last run.

Laya, and why it isn't steering yet

Laya is a small decision model bundled with Clyde that runs locally. It watches for a model repeating itself and hands the turn on when it is confident. What else it does

Scripts and CI
clyde -p runs one turn with JSON output and exit codes.
Sandbox
Shell commands write only inside the project. Reading a .env or key file asks first.
MCP
Servers work over stdio, HTTP and SSE, with OAuth sign-in.
Sub-agents
Agents and teams run in parallel, in the background if you like.
Your existing setup
Reads the memory files, skills, hooks and MCP servers you set up for Claude Code, Codex, Cursor or Gemini CLI.
Saved plans
The plan you approve in plan mode survives /compact and --resume. /plan marks phases done.
Review and sessions
/review reads your changes, a commit or a branch without editing. clyde sessions searches old sessions.
The install
clyde doctor, update and uninstall. Updates follow main or tagged releases and never install by themselves.

Editor support over the Agent Client Protocol, a read-only SQL tool and the rest are in the README.

Limits

  • Source-available, not open source: free for noncommercial use under the PolyForm Noncommercial License 1.0.0. Commercial use needs written permission. The first run asks you to type "I accept".
  • One maintainer, and few users so far. Expect rough edges.
  • Needs Python 3.14+ on macOS or Linux. The install is about 850 MB, mostly PyTorch for the bundled Laya model.
  • Not tried in the wild yet: editor support over ACP (Android Studio doesn't support ACP agents) and the Linux sandbox (bubblewrap), which has only been tested through its arguments.
  • Some providers don't report token usage, so cost tracking can't count them.
