ClydeCLI

A coding-agent harness for the terminal. Bring any LLM; Clyde gives it tools, permissions, a sandbox, undo and sessions.

curl -fsSL https://raw.githubusercontent.com/dea6cat/ClydeCLI/main/install.sh | sh

The model can be one of 13 providers, a local model through Ollama or LM Studio, or any OpenAI- or Anthropic-compatible endpoint. Written in Python, free for noncommercial use. Bonnie, the same engine in a browser page, comes in the same install. Prefer pipx? pipx install --python python3.14 git+https://github.com/dea6cat/ClydeCLI (needs Python 3.14) works too.

Bring any model

Local or hosted
Run a model on your own machine with Ollama or LM Studio, or bring your own key for 13 hosted providers or any OpenAI- or Anthropic-compatible service. Where to get a key.
Switch any time
Pick the model per session with /model, or let cardShuffle deal one each turn from the models that passed your /eval.
Sessions you can find again
Every turn is saved. /resume or clyde -c picks one up, clyde sessions search finds an old one by what was said, and /rewind undoes a change.
Memory you control
It reads the memory files you already keep (CLYDE.md, CLAUDE.md, AGENTS.md, GEMINI.md) and keeps notes you ask it to remember, in plain markdown you can edit. It learns nothing on its own.

A real session

A three-file project with a leap-year bug, NVIDIA's muse-glimmer-30b in all-in mode, then /rewind to undo the fix. The dim italic lines are the model's own thinking.

The deal

Each turn, Clyde deals from the models you have. The pile deals on its own, naming each model as its card comes out. Put your pointer on it and move up and down to pick one yourself.

Bonnie, Clyde’s luv accomplice

clyde luv bonnie opens Bonnie at localhost:8080 on your own machine: the same engine, tools and sessions in a browser page, with her own voice. Queue, steer or stop a turn, attach images and text files, search the web with sources, and see the files Clyde wrote in an Artifacts view. Connect a model provider with a guided, tested key flow, pin sessions, choose or make the project folder, and set prompts to run on a schedule (read-only unless you allow edits). Make the page yours in Customize. bonnie luv clyde goes the other way and starts the terminal. See Bonnie.

And more

Tune a local model's memory and window, deal a model each turn and re-deal when one fails, check which models really work, ask four at once, sandbox every command, connect MCP servers and sub-agents. See every feature, with recordings and real results.

Limits

  • Source-available, not open source: free for noncommercial use under the PolyForm Noncommercial License 1.0.0. Commercial use needs written permission. The first run asks you to type "I accept".
  • One maintainer, and few users so far. Expect rough edges.
  • Needs Python 3.14+ on macOS or Linux. The install is about 850 MB, mostly PyTorch for the bundled Laya model.
  • Not tried in the wild yet: editor support over ACP (Android Studio doesn't support ACP agents) and the Linux sandbox (bubblewrap), which has only been tested through its arguments.
  • Some providers don't report token usage, so cost tracking can't count them.
