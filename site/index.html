What's in the deck

Clyde is the harness around your model: everything it needs to read, change and check real code, sorted into four suits.

♠

Models

Any provider
13 built in, local Ollama and LM Studio, or any OpenAI-compatible API with /login.
Model eval
/eval tests tool calls and grades 11 tasks. Broken models are hidden.
cardShuffle
One model name that picks a real model each turn, with fallback. Deal a hand.
Local models that fit
/models local rates downloads against your machine first.
Laya
A bundled local model that spots stuck loops.

cardShuffle: one model name, the whole table behind it

Choose cardShuffle as your model and Clyde hands each turn to a real one, ranked by its own /eval. If that model errors, stalls or loops, the next card takes over mid-turn.

Choose a tier
    Press Deal to start a turn.

    The first eight cards of each tier from a real /eval of 52 models. The free tier adds example local models; yours comes from your own results.

    Laya keeps the table honest

    Laya is a small decision model bundled with Clyde. It runs on your machine, with no key and no network, and answers in about a tenth of a second.

    Is the model going in circles?

    From the sixth tool call, every third round, Laya checks whether the dealt model keeps repeating itself. A confident yes hands the turn to the next card.

    On: switches models when stuck

    How hard is this request?

    Every turn gets a difficulty score. At first it is only recorded. It starts choosing models for house once your own turns show that higher-scored requests really take more work. /laya shows the evidence.

    Watching only: not yet choosing models

    Your models, your keys

    No account with us and no proxy in between. Requests go straight from your machine to the provider you choose.

    AnthropicOpenAIGoogle GeminiOpenRouter MistralNVIDIADeepSeekCerebras GLMMiniMaxOllama Cloud Ollama, localLM Studio, localAny OpenAI-compatible API

    Up and running in three steps

    Python 3.14+ on macOS or Linux, and a key for any provider you like.

    Install

    Sets up uv if needed, then Clyde, then runs clyde setup.

    curl -fsSL https://raw.githubusercontent.com/dea6cat/ClydeCLI/main/install.sh | sh

    Connect

    Pick a provider and paste its key, or export one.

    clyde login

    Work

    Start it in your project and say what's broken.

    clyde
    Straight talk
    • The install is about 850 MB, mostly PyTorch for Laya, the bundled local model.
    • It's young: one maintainer, not yet hardened by a big user base. Issues and PRs are welcome.
    • Editor support is new: clyde --acp speaks the Agent Client Protocol, tested against the protocol but not yet in a real editor.

    Pull up a chair.

    One line installs it. Your models do the rest.
