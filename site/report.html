Report an issue

Write it here and the button opens a new GitHub issue with your text filled in. You read it over and press Submit on GitHub, where a free account is needed. Nothing is sent from this page.

Check the open issues and the release notes first: it may already be fixed in the latest version.

Do not paste API keys or private code. Issues on GitHub are public.

Prefer to write it on GitHub directly? Start a blank issue. For a security problem, follow the security policy instead of opening a public issue.
